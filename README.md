# 🚀 Featured Projects:
**🤖 AI Interview Practice Bot** — Scores responses across 5 dimensions using a hand-labeled ML pipeline (TF-IDF + Random Forest), with Groq/Llama 3.3 generating adaptive coaching feedback and answer rewrites.
🔗 [Repo](https://github.com/NaafiahKawnain/AI-Interview-Practice-Bot)

**📊 Student Performance Predictor** — Gradient Boosting Classifier predicting student pass/fail outcomes — 91% accuracy, 80% precision on at-risk students. Deployed as a Streamlit app.
🔗 [Repo](https://github.com/NaafiahKawnain/Student-Performance-Predictor)

**🔍 RAG Question Answering System** — Retrieval-Augmented Generation pipeline using FAISS vector search, all-MiniLM-L6-v2 embeddings, and Groq LLM. Served via FastAPI with Swagger UI.
🔗 [Repo](https://github.com/NaafiahKawnain/RAG-Question-Answering-System)

**🧠 Sentiment Analysis Pipeline** — Benchmarks classical ML (TF-IDF + Logistic Regression) against DistilBERT on the IMDB dataset to compare traditional NLP vs transformer performance.
